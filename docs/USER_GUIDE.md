# 👥 User Guide - Metrobank Scholarship Management System

## Welcome to the Metrobank Scholarship Management System

This guide will help you navigate and use the scholarship management system effectively. Whether you're a student, registrar, or administrator, this guide covers all the essential features and workflows.

## 🎯 Getting Started

### System Requirements

- **Web Browser**: Chrome 90+, Firefox 88+, Safari 14+, or Edge 90+
- **Internet Connection**: Stable internet connection required
- **Screen Resolution**: Minimum 1024x768, recommended 1920x1080
- **JavaScript**: Must be enabled in your browser

### First-Time Login

1. **Access the System**: Navigate to the system URL provided by your administrator
2. **Login Credentials**: Use your provided email and password
3. **Password Reset**: If you forgot your password, contact your system administrator
4. **Dashboard**: After successful login, you'll see your personalized dashboard

## 📚 Scholarship Renewal Management

### Creating New Renewal Batch

#### Step 1: Access Renewal Management

1. Navigate to **Renewals** in the main menu
2. Click **"Create New Renewal"** button
3. Fill in the required information:
   - **School Year**: Select the academic year
   - **Semester**: Choose the semester
   - **Year Level**: Select the year level
   - **Campus**: Choose the campus

#### Step 2: Configure Settings

- **Validation Rules**: Set up validation criteria
- **Approval Workflow**: Configure approval process
- **Notification Settings**: Set up email notifications
- **Deadline**: Set submission deadline

#### Step 3: Generate Renewal List

- Click **"Generate Renewal List"** to create the batch
- Review the generated list
- Make any necessary adjustments
- **Save** the renewal batch

### Managing Renewal Records

#### Viewing Renewals

- **List View**: See all renewals in a table format
- **Filter Options**: Filter by status, campus, year level
- **Search**: Search for specific students
- **Sort**: Sort by various columns

#### Updating Renewal Status

1. **Select Records**: Choose the renewal records to update
2. **Bulk Actions**: Use bulk actions for multiple records
3. **Individual Updates**: Click on individual records
4. **Save Changes**: Confirm your changes

#### Validation Process

- **GPA Validation**: Check GPA requirements
- **Document Validation**: Verify required documents
- **Status Updates**: Update validation status
- **Comments**: Add validation comments

### Document Management

#### Uploading Documents

1. **Select Renewal**: Choose the renewal record
2. **Upload Files**: Drag and drop or browse for files
3. **File Types**: Supported formats (PDF, ZIP)
4. **Processing**: Wait for document processing
5. **Review**: Review extracted data

#### Document Processing

- **Automatic Extraction**: AI-powered data extraction
- **Progress Tracking**: Real-time processing status
- **Error Handling**: Automatic error detection
- **Manual Review**: Review and correct extracted data

#### File Management

- **View Files**: Preview uploaded documents
- **Download**: Download original files
- **Replace**: Replace existing files
- **Delete**: Remove unnecessary files

## 🔄 Approval Workflows

### Creating Workflows

#### Step 1: Workflow Setup

1. Navigate to **Workflows** in the main menu
2. Click **"Create New Workflow"**
3. Fill in workflow details:
   - **Title**: Descriptive workflow title
   - **Description**: Detailed description
   - **Due Date**: Set completion deadline
   - **Priority**: Set workflow priority

#### Step 2: Assign Approvers

- **Select Approvers**: Choose from available users
- **Approval Order**: Set sequential approval order
- **Notification Settings**: Configure notifications
- **Escalation Rules**: Set up escalation procedures

#### Step 3: Configure Rules

- **Approval Criteria**: Define approval requirements
- **Rejection Rules**: Set rejection criteria
- **Timeout Handling**: Configure timeout actions
- **Notifications**: Set up notification preferences

### Managing Workflows

#### Workflow Dashboard

- **Active Workflows**: Currently running workflows
- **Pending Approvals**: Items awaiting your approval
- **Completed Workflows**: Finished workflows
- **Overdue Items**: Past due items

#### Approval Process

1. **Review Request**: Examine the workflow request
2. **Check Documents**: Review attached documents
3. **Make Decision**: Approve or reject
4. **Add Comments**: Provide feedback
5. **Submit Decision**: Complete the approval

#### Workflow Status

- **Pending**: Awaiting approval
- **In Progress**: Currently being processed
- **Approved**: Successfully approved
- **Rejected**: Rejected with reason
- **Overdue**: Past due date
